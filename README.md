# Готовый Telegram-бот с напоминаниями в Google Таблице

Ниже — полностью рабочий код. Копируй файлы, выполняй setup — и бот запустится.

## Что умеет

- `/start` — показывает твой `chat_id` и справку
- `/add текст | время` — добавить напоминание
- `/list` — список активных напоминаний
- `/del номер` — удалить
- фоновая проверка каждые 30 секунд → отправка «⏰ ...» в нужный чат
- всё хранится в Google Таблице, бот сам создаёт лист с шапкой

---

## 1. Установка

```bash
pip install "python-telegram-bot[job-queue]>=21.0" "gspread>=6.0" "google-auth>=2.30"
```

Создай папку проекта:

```
bot/
├── config.py
├── sheets.py
├── bot.py
└── credentials.json   ← положишь сюда ключ сервисного аккаунта
```

---

## 2. Подготовка Google

1. [Google Cloud Console](https://console.cloud.google.com/) → новый проект.
2. **APIs & Services → Library** → включи **Google Sheets API** и **Google Drive API**.
3. **APIs & Services → Credentials → Create credentials → Service account** → создай.
4. У сервисного аккаунта: **Keys → Add key → Create new key → JSON** → скачай файл → переименуй в `credentials.json` → положи в папку проекта.
5. Скопируй email сервисного аккаунта (вида `xxx@xxx.iam.gserviceaccount.com`).
6. Создай новую Google Таблицу → **Поделиться** → добавь этот email с правами **Редактор**.
7. Из URL таблицы скопируй **ID** (между `/d/` и `/edit`).

## 3. Бот у @BotFather

`/newbot` → получи токен вида `123456:ABC-DEF...`.

---


```bash
python bot.py
```

В логах должно быть `Бот запущен. Интервал проверки: 30 сек`.

Открой своего бота в Telegram → `/start` → увидишь chat_id → добавь напоминание:

```
/add Проверить дедлайн | 06.10.2026 18:00
```

Через минуту проверь таблицу — там появится строка. А когда наступит время — придёт сообщение и в колонке `sent` появится `TRUE`.

## Частые проблемы

| Ошибка | Причина / решение |
|---|---|
| `The caller does not have permission` | Забыл расшарить таблицу на email сервисного аккаунта (Редактор). |
| `SpreadsheetNotFound` | Неверный `SHEET_ID` или таблица не расшарена. |
| `Не понял время` | Формат не подошёл. Используй `2026-10-06 10:00` или `06.10.2026 10:00`. |
| Напоминание не приходит вовремя | Проверь `TIMEZONE` в `config.py`. |
| Бот молчит | Загляни в консоль — там будут логи с ошибкой. |

## Что можно добавить потом

- команду `/edit` для смены времени;
- поддержку «повторяющихся» напоминаний (`daily`, `weekly`);
- кнопки «Отложить на 10 мин / 1 час»;
- уведомление за 15 минут до события (вторая колонка `remind_at_2`);
- webhook вместо polling, если бот станет нагрузочным.
